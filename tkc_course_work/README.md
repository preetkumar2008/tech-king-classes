# Tech King Classes — Starter

First coded homepage foundation for the Tech King Classes LMS.

## Included
- Next.js + TypeScript starter
- Responsive header + hero
- Tech King logo + mascot integration
- Featured course cards
- Why Tech King Classes section
- Preet Kumar instructor section
- Free notes and tests teaser
- Support CTA and footer
- Clean educational + blue/cyan + dark brand system

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000
