# Lesson Content + Video Player Update

This update keeps the existing Admin Module/Lesson system and improves the student lesson experience.

## Included
- YouTube normal links, `youtu.be`, Shorts and existing embed URLs are converted to privacy-enhanced `youtube-nocookie.com` embeds.
- Vimeo video URLs are converted to Vimeo player embeds.
- Video iframe uses lazy loading and a safer referrer policy.
- Notes button is labelled `Open Notes / PDF` and continues to use the admin-supplied URL.
- Existing lesson progress, Mark Complete, Previous/Next navigation, quiz and certificate systems are preserved.

## Admin workflow
Admin > Content Management > select Course > select Module > Add/Edit Lesson:
- Lesson title
- Slug
- Description
- YouTube / video URL
- Notes / PDF URL
- Lesson order
- Free Preview / Protected lesson
